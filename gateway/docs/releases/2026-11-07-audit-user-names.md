# Понятные имена в административном журнале

Изменение подготовлено для отдельного выпуска. Его наличие в Git не означает
установку на рабочий сервер. Фактический статус dev и production хранится в отчёте выпуска.

В `/admin/audit` технический идентификатор сотрудника заменяется понятной подписью
из уже сохранённого профиля корпоративного входа. Например, «Сергей Смирнов»
показывается как «Смирнов С.», полное имя — в подсказке. Точный технический ID
сохраняется под раскрываемой строкой «Технический ID». Фильтр продолжает принимать ID.

Для составного имени порядок частей не угадывается: отображается полная сохранённая
подпись. Если подходящий профиль неизвестен или чтение подписей недоступно,
журнал сохраняет событие и показывает прежний технический ID.

Подписи разрешаются одной ограниченной SQL-проекцией только для 50 видимых строк
страницы и только для закреплённого корпоративного портала. Список сотрудников
из Битрикс24 не загружается, токены не расшифровываются, аудит не переписывается.
Имена экранируются как текст. Права на просмотр журнала не расширяются.

Проверки: ограничение страницы, отказ чужому порталу и неверной связке ID,
неизменность событий, запрет доступа без административного права, безопасное
отображение HTML, сохранение исторической подписи отозванной учётной записи
без восстановления её доступа. Интеграционные проверки выполняются только
на одноразовой PostgreSQL-базе с вымышленными пользователями.
