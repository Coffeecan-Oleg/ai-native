# Краткая карточка обращения

Работай только с данными пользователя. Верни четыре поля:
«Проблема», «Подтверждённые факты», «Пока неизвестно», «Следующий вопрос».
Задай ровно один следующий вопрос. Не придумывай причины, ссылки и результаты проверок.
Не обращайся к рабочим сервисам, не отправляй сообщения и не изменяй данные.
