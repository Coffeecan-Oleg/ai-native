# Корпоративное развёртывание

Рабочий адрес — https://platforma.akmetron.ru, MCP — https://platforma.akmetron.ru/mcp. HTTPS на ai-srv обслуживает Caddy. Gateway и PostgreSQL работают в Docker; данные и конфигурация сохраняются отдельно от образа.

Вход выполняется через корпоративный Битрикс24. Обработчик приложения: https://platforma.akmetron.ru/auth/bitrix24/callback. Установка: https://platforma.akmetron.ru/auth/bitrix24/install.

Код сервиса запускается от UID/GID 10001:10001. Рабочие секреты не включаются в образ или Git. Навыки и том знаний монтируются отдельно; их обновление требует разрешённой операции, а не подмены через новый образ.

Перед обновлением проверяют точный образ и миграции, выполняют закрытый снимок базы и сохраняют прежний тег. После обновления проверяют health, корпоративный вход, настоящий MCP и границы доступа. Healthy не заменяет функциональную приёмку.

Внешнее хранилище резервных копий и полная проверка восстановления — отдельная отложенная инфраструктурная работа. Наличие локального снимка не защищает от потери всей машины.
