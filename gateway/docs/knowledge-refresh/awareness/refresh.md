# Обновление карты знаний

1. Зафиксировать точный состав выпуска, Git-коммит, идентификатор образа и фактическую приёмку. Отделить подготовку на копии от применения на сервере.
2. Сопоставить инструкции с разрешёнными функциями: вход, каталог, диагностика, версии навыков, журналы и интеграции. Удалять учебные сведения из актуального текста только в согласованном пакете.
3. Подготовить изменения на копии и сохранить исходные SHA256. Проверить ссылки, границы доступа и примеры запросов. Не добавлять пароли или персональные переписки.
4. После согласования применить через разрешённый административный процесс со снимком и откатом. Ограниченная SSH-роль не даёт права произвольно менять том знаний.
5. Перечитать документы через настоящий MCP и открыть опубликованные статьи БЗ 2.0 после перезагрузки.

БЗ 2.0 — точка входа для сотрудников; этот комплект — компактный справочник для MCP. Автоматической синхронизации между ними пока нет. Подготовленный текст не является опубликованной инструкцией. По каждому выпуску фиксируются отдельно обновлённые статьи и применённые файлы MCP.
