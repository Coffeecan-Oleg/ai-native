# Возможности корпоративной Платформы

| Возможность | Как использовать | Ограничение |
|---|---|---|
| Корпоративный вход | Открыть приложение в akmetron.bitrix24.ru | Только действующие внутренние сотрудники закреплённого портала |
| Навыки | Каталог и gateway_corporate_skill_list/read | Текст читает и применяет клиент; код на сервере не исполняется |
| Черновики и версии загрузок | /platforma/skills/manage | Автор видит свои материалы, владелец — очередь; публикация и архив только владельцем |
| Проверка MCP | /platforma/connection и готовый запрос с меткой | Подтверждает только реальный собственный MCP-вызов; не определяет место выполнения чата |
| Общие знания | gateway_knowledge_space_list/search/document_get | Только разрешённые общие пути; не личная память |
| Учёт навыков | События started/completed/failed и собственная статистика | Клиент должен передать события; чтение инструкции не равно запуску |
| UniSender | getLists и getContactCount через разрешённый маршрут | Отдельный доступ; нет отправки, изменения данных или выгрузки адресов |

Учебные заявки и демонстрационные операции отключены. CRM/заявки Битрикс24, 1С, почта и Zabbix через этот профиль не подключены. Вход через Битрикс24 сам по себе не даёт доступ к CRM.

Новая версия навыка не меняет постоянный ID. До её публикации MCP выдаёт прежнюю опубликованную версию. Архив закрывает дальнейшее чтение, сохраняя материалы, историю и статистику; уже прочитанный текст не исчезает из чатов клиентов.
