# Паспорт корпоративной Платформы

Назначение: дать внутренним сотрудникам общий каталог навыков и контролируемый доступ их ИИ-приложений к разрешённым функциям компании.

Вход — только через akmetron.bitrix24.ru. После успешного личного входа действующий внутренний сотрудник получает базовый доступ автоматически. Внешние пользователи и сотрудники другого портала не подходят. Администрирование и рабочие интеграции разрешаются отдельно.

Рабочий сервис: https://platforma.akmetron.ru, MCP — /mcp. Сервис перенесён на ai-srv; песочница используется отдельно для проверок. Код — Coffeecan-Oleg/ai-native, корпоративный каталог gateway. Версия сервера определяется по идентификатору образа, Git-коммиту и /healthz, а не по имени ветки.

Состав: Gateway, PostgreSQL, сохраняемые файловые тома, HTTPS, корпоративный вход, библиотека навыков, журналы и ограниченное чтение UniSender. Самостоятельный агент Zabbix в этот шлюз не подключён.

Личная память, чужая статистика и администрирование не входят в базовый доступ. Наличие инструкции об интеграции не означает, что её API уже подключён.
