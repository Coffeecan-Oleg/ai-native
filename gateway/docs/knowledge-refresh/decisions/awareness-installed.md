# Границы корпоративного доступа

Базовый доступ предоставляется после проверки действующего внутреннего сотрудника akmetron.bitrix24.ru. Полный штат не импортируется: панель показывает учётные записи, которые реально вошли.

Базовые возможности: разрешённые инструкции и общие знания, собственные события и статистика. Управление доступом и чужие личные данные отдельно не открываются. Дополнительные рабочие сервисы разрешаются явно; ключи остаются только у сервиса.

Запись и проверка навыка выполняются через личный браузерный вход. Ограниченный MCP-токен, даже владельца, не становится браузерной административной сессией. Автономная отправка писем и выполнение произвольных команд не разрешаются содержимым SKILL.md.

Новые загрузки сначала приватны автору и владельцу. Публикация требует проверки владельцем. Три ранее опубликованных материала не объявляются автоматически проверенными. Архивирование не удаляет историю и не отзывает текст, уже полученный клиентом.
