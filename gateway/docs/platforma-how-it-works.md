# Как это работает: справочный раздел учебной Платформы

`GET /platforma/how-it-works` — общая памятка, следующие шаги для обмена
навыками, данными и агентами, пример UniSender и карточка подключения сервиса.
Ссылка находится в меню владельца и одобренного учебного участника.

`GET /platforma/how-it-works/download?document=memo|card|message` выдаёт один
из трёх фиксированных UTF-8 файлов. Другие параметры и повторённый `document`
отклоняются. Произвольные пути, загрузка файлов и изменение данных отсутствуют.

Оба адреса требуют личного браузерного входа. Для участника при каждом запросе
проверяется действующее одобрение и его связанные grants; отзыв и истечение
закрывают страницу и скачивания, включая уже выданную cookie. Ограниченный
MCP-токен не используется как браузерная сессия. Раздел закрыт при выключенном
учебном onboarding. Новых scopes, grants, MCP-инструментов и миграций нет.

Карточка заполняется только в памяти страницы. Она не содержит формы отправки,
не использует сеть, local/session storage и не записывается в БД. Пользователь
копирует или скачивает `.txt` сам и передаёт администратору привычным способом.
При обновлении/закрытии окна ответы теряются; это явно указано над полями.
При запрете clipboard выделяется готовый текст с подсказкой ручного копирования.
Без JavaScript доступна пустая карточка для скачивания.

Контент: `gateway_mcp/help_assets/platforma-guide.json`, поведение карточки:
`platforma-guide.js`. Они включены в setuptools package-data. Весь текст
экранируется; пользовательские ответы остаются в textarea.value/textContent.
Скрипт статический, с уникальным nonce; CSP запрещает connect и отправку форм.
Страница и скачивания имеют `Cache-Control: no-store`, nosniff и запрет iframe.
Используется существующая тема Акметрон и локальные шрифты.

Памятка описывает проверенное состояние песочницы на 23.10.2026. UniSender и
запуск произвольных агентов не включены. Перед реальной интеграцией отдельно
согласуются данные, права, реквизиты, журналирование и проверка под разными людьми.
Реальные секреты, контактные списки и чужие OAuth-ссылки в карточку не вводят.

Проверки: `onboarding_tests/test_platforma_guide.py` — реальные HTTP-маршруты и
изолированная PostgreSQL `platforma_onboarding_test`, синтетические учётные записи.
Общая регрессия onboarding/Platforma/skill uploads/knowledge contract также нужна.

Обновление: только Gateway после закрытой резервной копии. БД, роли, сроки,
профили, локальный плагин, Timeweb и сборщик не меняются. При откате возвращается
предыдущий образ Gateway; более поздние данные БД и runtime сохраняются.
