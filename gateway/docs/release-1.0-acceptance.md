# Приёмка 1.0 обычным сотрудником

Статус: результат ожидается. Проверку выполняет действующий внутренний сотрудник
под своей учётной записью, без роли владельца. Администратор проверяет и публикует
только специально созданный для приёмки навык. Не передавайте пароль другому человеку.

Одна ссылка для коллеги: https://akmetron.bitrix24.ru/note/document/537/
Там размещён сценарий с файлом навыка. Если файл или инструкция недоступны,
зафиксируйте это как результат шага, а не создавайте реальную заявку или интеграцию.
Подробности цикла: [пошаговая инструкция](knowledge-base/06-skill-acceptance.md).

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть приложение Платформы в Битрикс24 | Панель внутри портала, своя учётная запись |
| 2 | Подключить в своём ИИ-приложении https://platforma.akmetron.ru/mcp и пройти личный OAuth | Подключение появилось именно в нужном чате |
| 3 | Взять готовый запрос в «Проверить подключение», выполнить и обновить результат | Запрос дошёл; личность совпадает; получен ID запроса |
| 4 | Загрузить вымышленный навык из инструкции, сохранить ID, отправить на проверку | Черновик, затем «На проверке», без общей публикации |
| 5 | Дождаться проверки и публикации владельцем | Опубликованная версия доступна через MCP |
| 6 | Прочитать и применить навык к вымышленному примеру | Ответ из инструкции; реальные версия/SHA/квитанция чтения |
| 7 | Открыть собственный журнал | Серверное чтение есть; запуск есть, только если клиент передал события |
| 8 | Подготовить TXT, скачать и открыть файл на компьютере | Текст читается; сервер, версия и запрос совпадают с проверкой |
| 9 | Проверить границы | Нет чужой статистики, памяти и управления; собственный журнал доступен |

Для шагов 3 и 6 нужны реальные вызовы MCP. Пересказ ассистента без вызова не
считается успешной проверкой. Файл на диске и просмотр текста в панели — разные
результаты. Если скачивание не получилось, текст можно скопировать для диагностики,
но пункт скачивания остаётся непройденным.

## Что вернуть владельцу

```text
Проверка Платформы 1.0
Дата и время МСК:
Браузер и версия:
ИИ-приложение, версия и среда чата:
Роль: обычный сотрудник (не владелец)
Адрес MCP из настройки:
Версия сервера из отчёта:
ID навыка и опубликованная версия:
ID серверного запроса / квитанция чтения:
Шаги 1–9: для каждого — пройден / ошибка / не проверен
Файл действительно скачан и открыт на диске: да / нет
Если ошибка — действие, ожидаемый результат и фактический текст:
Приложения: свой TXT и снимок ошибки без секретов
```

Не включайте cookies, Authorization, полные ссылки OAuth, пароли и чужие разговоры.
Владелец сопоставляет ответ с журналом и текущей версией. Один тест не подтверждает
все приложения или всех сотрудников. Выдавать роль администратора ради зелёного
результата нельзя. Проверка владельцем и синтетический тест не подменяют этот лист.
