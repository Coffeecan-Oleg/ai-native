# Пакет сети и непривилегированного процесса — подготовлен, не применён

База: принятый metrics-closed-7fbc5e40ab95. Код бизнес-функций не меняется.
Образ-кандидат добавляет UID/GID10001, закрытую маску umask077 и групповые права
чтения существующего кода. Обнаружена старая копия исходников в /app; действующий
console script импортирует установленный пакет из site-packages. Копию /app не
принимали за runtime при проверках. Сведение этих источников относится к следующему
направлению воспроизводимого релиза, а не к данному пакету.

Развёртывание меняет image/user/host_ip сервиса gateway, метку выпуска и права
конкретных семи bind/volume-источников. Root остаётся владельцем конфигураций и
каталога, группе10001 выдаётся чтение; три тома становятся доступны сервису на
запись. Содержимое существующих файлов не изменяется.

Сетевой guard — отдельный root-owned Python-сценарий и oneshot unit.
В raw/PREROUTING IPv4 и IPv6 добавляется точечный переход: iif eth0, TCP dport8000
→ частная цепочка DROP. Не сбрасываются таблицы и общие политики; локальный путь
loopback, SSH и другие порты этим правилом не затрагиваются. Выбрана точка до
DNAT/маршрутизации: она закрывает и host INPUT, и Docker FORWARD и не зависит от
порядка Docker ACCEPT-правил. Unit запускается до Docker и не снимает защиту
при обычном stop. Удаление правила — отдельный явный откат администратора.

Наблюдённый внешний HTTPS внутри LXC приходит через loopback/docker-proxy.
Исполнение команд на jump-host недоступно, поэтому внешний прокси/форвардер
не изменялся и полностью не инвентаризирован. Живая приёмка после применения
обязательна: сохранение этого пути нельзя обещать только по стендовому тесту.

Перед изменением — новый закрытый backup конфигурации, БД, томов и исходных
POSIX-метаданных. На время apply ставится root-owned rollback timer на600с,
который работает при обрыве SSH. После внешней проверки HTTPS, MCP и ручного
входа Bitrix24 администратор выполняет commit, отменяющий таймер.
При ошибке/истечении окна возвращаются предыдущие compose/.env/image/права;
снимается только собственное правило. БД и содержимое томов не откатываются.
Данные, записанные за время нового запуска, сохраняются.

Статья docs/knowledge-base/02-operations-and-development.md — черновик для
просмотра. Публикация допустима после согласования и успешной живой приёмки
сети/UID; до этого утверждения соответствующего раздела не являются текущим
состоянием сервера. Права БЗ и других статей не меняются, статья491 не затрагивается.
