# Как проверить файлы и ссылки своего навыка

Статус: функция входит в принятую основу a14c4f7; текущее состояние выпуска и границы приёмки указаны в [описании релиза](../release-1.0.md). Этот файл — исходник документации, а не доказательство публикации этой редакции в БЗ 2.0.

Навык — инструкция для ИИ и приложенные к ней материалы. Ссылка на файл внутри инструкции должна вести на файл того же пакета. Если автор забыл приложить файл или изменил его имя, ассистент не сможет прочитать нужный материал.

В карточке сохранённой версии предусмотрен раздел «Проверка файлов и ссылок». Он помогает автору и владельцу найти такие ошибки перед публикацией. Проверяются только загруженные пользовательские навыки, которыми управляют через раздел черновиков и версий. Файлы на сервере, встроенные навыки и статьи Битрикс24 этим разделом не изменяются.

## Где открыть проверку

1. Откройте в Битрикс24 приложение «Платформа Акметрон», затем «Каталог навыков» → «Мои черновики и версии».
2. Откройте свой черновик. Владелец Платформы также может открыть материал из очереди проверки.
3. Найдите раздел «Проверка файлов и ссылок». В нём указаны номер сохранённой редакции, версия материала и замечания с названием файла и номером строки.

Отчёт относится к сохранённой редакции. Текст, который вы ещё не сохранили в форме, в него не входит. Другие сотрудники не получают доступ к вашему черновику благодаря этой проверке. Через MCP доступна прежняя опубликованная версия, если она существует.

## Пример: забыли приложить инструкцию

В SKILL.md добавлена ссылка с подписью «правила» и адресом guides/rules.md. Инструкция просит ИИ прочитать этот файл перед подготовкой ответа.

В ZIP нет файла guides/rules.md. Проверка покажет: «Ссылка указывает на файл, которого нет в этой редакции архива», а рядом — SKILL.md и номер строки.

Что делать: добавьте guides/rules.md в ZIP или исправьте ссылку на существующий файл. Имена и регистр букв должны совпадать. Загрузите исправленный пакет через «Новая редакция», сохраните и снова откройте карточку. Убедитесь, что вы читаете новую редакцию и замечание исчезло. Старая редакция останется в истории со своими материалами и своим отчётом.

Поддерживаются базовые Markdown-ссылки и изображения, включая относительные пути, а также ссылки вида [текст][метка] с определением метки в том же файле. Примеры ссылок внутри обычных блоков кода не считаются действующими ссылками. Сложную разметку проверяйте вручную.

## Какие ещё замечания можно увидеть

| Замечание | Следующий шаг |
|---|---|
| Версия SKILL.md отличается от версии карточки | Сверьте поле version в заголовке файла и версию, которую сохраняете в карточке. При обновлении материала укажите согласованную новую версию. |
| Ссылка выходит за пределы архива | Приложите нужный ресурс к навыку и используйте относительный путь внутри пакета. Доступ к диску вашего компьютера или сервера не предоставляется. |
| Не найдена метка Markdown-ссылки | Добавьте определение метки в том же файле или замените ссылку обычной ссылкой на файл. |
| Указан прежний адрес Платформы | Проверьте контекст. Для действующего подключения используйте https://platforma.akmetron.ru/mcp. Историческую цитату можно оставить с пояснением. |
| Неверный формат requirements.json | Исправьте декларацию по примеру ниже. Отсутствие этого необязательного файла само по себе не является ошибкой. |
| Достигнут лимит проверки | Остальные материалы просмотрите вручную. Отчёт ограничен 20 000 строками, 500 ссылками и показывает первые 50 замечаний; строки длиннее 8192 символов пропускаются с предупреждением. |

## Необязательная декларация операций

requirements.json описывает, какие действия предлагает автор навыка. Для текстовой задачи достаточно такого файла в корне пакета:

```json
{
  "schema": 1,
  "operations": [
    {
      "id": "draft",
      "title": "Подготовить черновик ответа",
      "kind": "assistant"
    }
  ]
}
```

Проверка допускает схему 1, от 1 до 10 операций и файл размером до 8 КиБ. Вид assistant означает текстовую работу в ИИ-приложении. Вид route — заявленный серверный маршрут; unavailable — операция, которую автор считает неподключённой. Вид route требует поля route с точным именем маршрута. Объявление маршрута не создаёт интеграцию и не выдаёт права. Проверка возможностей опубликованного навыка описана в [отдельной инструкции](07-skill-capabilities.md).

## Что результат подтверждает

Отчёт показывает найденные в сохранённых файлах проблемы в пределах перечисленных правил. Проверка читает текст из сохранённой редакции, сверяет его целостность и не выполняет приложенный код. Внешние сайты не открываются. Веб-ссылки, якоря, абсолютные серверные пути и HTML требуют самостоятельной проверки.

Нулевое количество замечаний не подтверждает безопасность смысла инструкции, качество ответа ИИ, доступность внешнего сервиса или права сотрудника. Публикация остаётся отдельным действием владельца после проверки материала. Подробнее: [цикл версий](05-skill-versions.md) и [приёмка навыка](06-skill-acceptance.md).

Для разработчика: отчёт вычисляется заново для конкретной сохранённой редакции после проверки доступа к ней. Он не сохраняет новые события, не меняет состояние навыка и не требует отдельной миграции БД. Сам цикл черновиков и версий из предыдущего выпуска требует миграции 0026.
