# Платформа Акметрон — корпоративный вход и MCP

Для чего нужна Платформа
Платформа даёт сотрудникам общий каталог навыков и контролируемый доступ ИИ-ассистентов к разрешённым серверным функциям. Навык — текстовая инструкция; инструмент — функция сервера. Загрузка навыка не создаёт интеграцию с сервисом и не запускает фонового агента.

Как войти в панель
В Битрикс24 откройте приложение «Платформа Акметрон»: https://akmetron.bitrix24.ru/marketplace/app/341/
Панель открывается внутри Битрикс24. Базовый доступ получает действующий внутренний сотрудник портала akmetron.bitrix24.ru после успешного личного входа. Аккаунты других порталов и внешних пользователей не подходят. Отдельного одобрения администратора для базового доступа нет.

Как подключить ИИ-ассистента
В приложении, которое поддерживает удалённые MCP-серверы с OAuth, добавьте адрес:
https://kromin.axion-test.akmetron.ru/mcp
Пройдите личный вход через корпоративный Битрикс24. Название пункта настроек зависит от приложения. Вход в панель и подключение MCP — разные действия. Открытие /mcp в обычной вкладке может вернуть Authentication required: это адрес для клиента MCP, которому нужен токен.

Первый запрос своему ассистенту
«Через подключённый MCP Платформы вызови gateway_access_profile, затем прочитай серверный каталог через gateway_corporate_skill_list. Покажи названия и постоянные ID доступных навыков. Ничего не изменяй. Если инструменты недоступны в этом чате, прямо скажи, что серверный вызов не выполнен».
Ожидаемый результат: подтверждение корпоративной учётной записи и фактический список навыков с сервера. Наличие плагина в настройках само по себе не подтверждает доступ инструментов в текущем чате.

Как поделиться навыком
В панели откройте «Каталог навыков» → «Загрузить навык». Укажите понятное название, загрузите Markdown-файл или ZIP с SKILL.md. В карточке навыка скопируйте готовый запрос для своего ассистента. При переименовании постоянный ID сохраняется. Загруженный текст читает и применяет ассистент в вашем приложении; сервер не запускает его как программу. Используйте только разрешённые к передаче сведения, без паролей и ключей.

Что видно в учёте
Сотрудник видит собственный журнал обращений к MCP и собственные события применения навыков. Событие навыка появляется, когда приложение передало его начало и результат; чтение файла само по себе не доказывает выполнение. Владелец видит раздел «Сотрудники и входы»: только учётные записи, которые успешно вошли, без импорта всего штатного состава. Отдельно учитываются вход в панель, авторизация MCP и успешный вызов инструмента. Эти отметки не означают, что человек сейчас онлайн. Для старых событий без метки канала дата авторизации MCP может отсутствовать.

Границы доступа
Личная память, чужая статистика и управление правами не входят в базовый доступ. Рабочий UniSender требует отдельного разрешения; доступны только чтение названий списков и подсчёт контактов. Отправка не подключена. Учебные заявки и демонстрационные операции в корпоративном режиме отключены. Доступ к заявкам или CRM Битрикс24 этим входом автоматически не создаётся.

Актуальные инструкции: https://akmetron.bitrix24.ru/note/workspace/29/
Инструкции добавляются по мере появления и проверки рабочих функций. Не передавайте администратору пароли, токены и полные ссылки OAuth. Для диагностики достаточно названия приложения, времени ошибки и её текста без секретов.
