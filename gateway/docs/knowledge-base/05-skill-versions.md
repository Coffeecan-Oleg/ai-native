# Как загрузить навык, выпустить новую версию и убрать его в архив

Навык — текстовая инструкция для вашего ИИ-приложения. Загрузка не подключает сервис и не запускает код.

## Первая загрузка

1. Откройте приложение «Платформа Акметрон» в Битрикс24 и выберите «Каталог навыков» → «Загрузить навык».
2. Введите понятное название. Выберите Markdown UTF-8 или ZIP с одним SKILL.md. В ZIP — до32 текстовых файлов, каждый до128КиБ, всего до2МиБ. Не загружайте пароли, ключи и сведения, которые запрещено передавать коллегам или выбранной модели.
3. Подтвердите условия и нажмите «Создать черновик». Черновик видят только автор и владелец. В общем каталоге и MCP он ещё не появился.
4. Откройте материал в «Мои черновики и версии», проверьте текст и нажмите «Отправить на проверку владельцу».
5. Владелец прочитает материал, проверит данные, ссылки и допустимые действия, затем опубликует или вернёт в черновик.

Ожидаемый результат публикации: тот же постоянный ID появился в общем каталоге. Другой сотрудник может прочитать опубликованную инструкцию через MCP. Проверка владельцем не гарантирует правильность любого ответа модели.

## Как воспользоваться

Откройте опубликованную карточку и скопируйте готовый запрос. Например:

> Прочитай через MCP навык с постоянным ID, который я указал. Покажи его название, версию и SHA256. Объясни назначение, необходимые инструменты и что требует моего подтверждения. Пока ничего не выполняй.

Укажите реальный ID из карточки; не используйте выдуманный пример как существующий навык. Если ассистенту недоступны инструменты, он должен прямо сообщить, что серверный вызов не выполнен.

## Новая версия

1. Откройте «Управлять версиями». Для ранее загруженного материала сначала сохраните текущую публикацию в истории этой кнопкой. Доступ коллег при этом не меняется и материал автоматически проверенным не становится.
2. Укажите новую метку версии, например1.0.1, и при необходимости загрузите новый файл. Без файла сохранятся прежние ресурсы. Название можно изменить в этой же форме.
3. Нажмите «Сохранить черновик», затем отправьте его на проверку. До публикации MCP продолжает выдавать прежнюю версию.
4. После публикации владельцем ID сохраняется, а содержимое и контрольные суммы обновляются. Старые материалы остаются в истории, доступной автору и владельцу.

Если карточка изменилась после открытия, сохранение остановится: обновите её и проверьте изменения. В одном навыке сохраняется до20 редакций; история не очищается автоматически. Новую версию нельзя выдать за старую метку при изменённом материале.

## Архив

Владелец нажимает «Перевести в архив». Навык исчезает из общего каталога и перестаёт читаться через MCP. Файлы, события и статистика сохраняются. «Восстановить из архива» возвращает последнюю опубликованную версию; неопубликованный черновик остаётся черновиком.

Уже прочитанная инструкция не исчезает из прошлых чатов сотрудников. Встроенные навыки этим разделом не заменяются: их обновляет администратор отдельным согласованным выпуском.
