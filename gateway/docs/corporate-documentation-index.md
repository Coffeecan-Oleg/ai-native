# Где искать актуальные инструкции корпоративной Платформы

Текущая точка входа — [кандидат релиза 1.0](release-1.0.md). Адрес MCP:
https://platforma.akmetron.ru/mcp. Личный вход — через корпоративный Битрикс24.

Последняя сохранённая приёмка основного сервера и dev относится к a14c4f7,
схема 28, 9 ноября 2026. Это не новый аудит сервера 10 ноября. Пакет 1.0
пока не опубликован. Приёмка обычным сотрудником и браузерное сохранение TXT
остаются открытыми; UniSender отключён, Zabbix отложен.

Статус prepared_not_deployed в corporate-documentation.json означает, что
пакет исходников документации сам не публикует статьи и не обновляет сервер.
Текущий реестр publications.json отделяет датированную историю от известных
страниц 495, 535 и 537. Новое равенство текста Git и БЗ не заявляется.
