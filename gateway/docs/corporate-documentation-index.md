# Где искать актуальные инструкции корпоративной Платформы

Рабочий адрес: https://platforma.akmetron.ru/mcp. Вход сотрудников — через akmetron.bitrix24.ru. Старые учебные материалы в репозитории не описывают текущие права и возможности рабочего сервера.

Материалы раздела knowledge-base — исходники статей. Наличие файла в Git не означает публикацию в БЗ 2.0 или применение релиза на сервере. Статьи публикуются после приёмки соответствующей функции. Автоматической синхронизации пока нет.

Перед публикацией статьи проверьте: функция установлена и принята; адрес рабочий; ссылки открываются; роль соответствует описанию; учебный пример явно обозначен и нужен для проверки корпоративной функции. Исторические практикумы, заглушки и старые инструкции Яндекса в корпоративную БЗ не переносятся.

Локальная проверка согласованности: python release/check-documentation.py. Она проверяет закреплённый перечень файлов, ссылки на файлы и адреса; не заменяет проверку опубликованных страниц и реальный вход в приложения.
