# Общие знания Платформы на dev

Адрес MCP для dev — https://platforma-dev.akmetron.ru/mcp. Для входа стенд использует отдельное приложение портала akmetron.bitrix24.ru. Живое подключение требует настроенного DNS, HTTPS и OAuth для этого стенда.

Справочник читает опубликованные для него документы этого пространства и указывает путь к источнику ответа.
