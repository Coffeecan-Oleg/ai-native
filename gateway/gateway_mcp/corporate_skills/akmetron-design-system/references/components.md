# Компоненты Акметрон — детальная спецификация

Восемь примитивов. В среде дизайна Акметрон они подключаются через `_ds_bundle.js`
(`window.DesignSystem_176d4c`). В обычном HTML/React/артефактах воспроизводи их по
этим спецификациям, используя токены из `assets/akmetron.css` (классы `.btn`, `.card`,
`.tag`, `.badge`, `.callout`, `.stat-value`, `.input-field` уже готовы в этом CSS).

Общие принципы для всех компонентов:
- Заголовочные элементы — Montserrat, текст — Inter.
- Углы скруглены всегда; границы — почти прозрачный хайрлайн; синяя граница только в active/selected.
- Цвет несёт смысл: синий = действие/акцент, розовый = риск/боль, серый = вторичное.
- Без эмодзи. Иконки — только тонкие линейные глифы Lucide со штрихом `#1C6BB0`.

---

## 1. Button — пилл-кнопка

Montserrat 700, форма пилюли (`border-radius: 999px`).

| Проп | Значения | Назначение |
|---|---|---|
| `variant` | `primary` · `secondary` · `ghost` | primary = синий градиент-заливка; secondary = прозрачная с хайрлайн-границей; ghost = только текст |
| `size` | `sm` · `md` · `lg` | паддинги по шкале 4/8/16/24 |
| `icon` | имя глифа Lucide | тонкий линейный глиф слева от текста |
| `disabled` | bool | `opacity: 0.4`, курсор `not-allowed` |
| `onClick` | fn | — |

Hover: primary светлеет (`#1C6BB0 → #3E8FD0`); secondary получает синюю границу + синий текст;
ghost — синий текст. **Без сжатия по нажатию.**

Классы CSS: `.btn .btn--primary` / `.btn--secondary` / `.btn--ghost`.

---

## 2. Card — градиентная панель

Базовый контейнер. Градиент `linear-gradient(160deg, #FFFFFF, #F6FAFD)` (светлее сверху, белый),
хайрлайн-граница, мягкая тень `--shadow-md`. Hover поднимает на `-4px`.

| Проп | Значения | Назначение |
|---|---|---|
| `variant` | `default` · `active` · `alert` | active = синяя граница + глоу; alert = розовая палитра, **только риски** |
| `padding` | число по шкале (24/32/48) | внутренний отступ |

- `active` — выбранное/важное состояние: синяя граница `--blue` + `--glow-blue`.
- `alert` — **исключительно** для проблем, рисков, болей: градиент `--alert-top → --alert-bottom`,
  розоватая граница. Никогда не использовать «для разнообразия».

Классы CSS: `.card` / `.card--active` / `.card--alert`.

---

## 3. Tag — пилл-чип категории/фильтра

Маленькая пилюля для категорий и фильтров. По умолчанию — приглушённая (серый текст,
почти прозрачная заливка). `active` — синяя заливка `--fill-blue` + синяя граница + синий текст.

| Проп | Значения |
|---|---|
| `active` | bool |

Классы CSS: `.tag` / `.tag--active`.

---

## 4. Badge — маркер статуса

Маленький UPPERCASE-маркер (Montserrat 700, трекинг 0.1em, 11px). Это **единственное**
место кроме эйброу-меток, где допустим верхний регистр.

| Проп | Значения | Назначение |
|---|---|---|
| `tone` | `blue` · `neutral` · `alert` | blue = акцент; neutral = вторичный; alert = **только проблемы** (розовый) |

Классы CSS: `.badge .badge--blue` / `.badge--neutral` / `.badge--alert`.

---

## 5. Callout — полупрозрачная синяя полоса

Иконка + одна строка акцента. Заливка `--fill-blue`, левая синяя граница 3px.
Одна короткая мысль, не абзац.

| Проп | Значения |
|---|---|
| `icon` | имя глифа Lucide |

Класс CSS: `.callout` (внутри — `<svg>` глиф Lucide + текст).

---

## 6. Stat — крупный числовой акцент

Большое синее число `#1C6BB0` (Montserrat 800, ~88px), доминирует над подписью.
**Значение всегда конкретно:** «67 ГГц», «<1 ч», «5 000 ₽» — не «широкий диапазон».

| Проп | Назначение |
|---|---|
| `value` | конкретное число с единицей |
| `label` | подпись под числом |
| `sublabel` | необязательная сноска |
| `align` | выравнивание |

Классы CSS: `.stat-value` + `.stat-label` + `.stat-sublabel`.

---

## 7. Input — светлое поле ввода

Белое поле, хайрлайн-граница, синеет в фокусе. Текст — фирменный нэйви `--text-1`.
Радиус `8px`.

| Проп | Назначение |
|---|---|
| `label` | подпись сверху |
| `hint` | подсказка снизу (третичный текст) |

Классы CSS: `.input-label` + `.input-field` + `.input-hint`.

---

## 8. Icon — тонкий линейный глиф Lucide

Только Lucide, синий штрих `#1C6BB0`, `stroke-width ≈ 1.6`. **Без эмодзи, без юникод-глифов,
без самодельных SVG сложнее круга/ромба.**

| Проп | Назначение |
|---|---|
| `name` | имя глифа: `radio`, `satellite`, `activity`, `zap`, `ruler`, `scan-eye`, `shield-check`… |
| `size` | размер |
| `stroke` | цвет штриха (по умолч. синий `#1C6BB0`) |
| `strokeWidth` | ~1.6 |

Подключение в HTML:
```html
<script src="https://unpkg.com/lucide@latest"></script>
<i data-lucide="radio"></i>
<script>lucide.createIcons();</script>
```

В React используй пакет `lucide-react`:
```jsx
import { Radio, Satellite, Activity } from "lucide-react";
<Radio size={20} strokeWidth={1.6} color="#1C6BB0" />
```

| СПОАИ | `shield-check` |
| Метрологическое оборудование | `ruler` |
| Фотоника (Оптика) | `scan-eye` |
| ГНСС оборудование | `satellite` |
