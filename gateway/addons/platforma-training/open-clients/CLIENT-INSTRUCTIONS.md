# Работа с учебной Платформой из OpenCode или OpenClaw

Это переносимая инструкция для ассистента, которую пользователь применяет в своём учебном проекте. Она не устанавливает приложение, не запускает фонового агента и не выдаёт права.

1. Используй личное подключение к https://kromin.axion-test.akmetron.ru/mcp. Прочитай gateway_access_profile и проверь фактические scopes. Не выбирай чужую identity, не передавай токены в чат.
2. Название Toolkit не доказывает движок. Выясни его из доступной информации приложения. OpenCode использует agent="opencode", client="opencode"; OpenClaw — agent="openclaw", client="openclaw". Если движок неизвестен, не подставляй Codex/Claude и не записывай выдуманный запуск. Попроси установить название приложения.
3. Прочитай platforma.context.get через gateway_call_tool и декларации нужных маршрутов через gateway_search_tools. Возможности backend не равны твоим личным разрешениям. Исходный снимок неизменяемый; разрешённые изменения идут только в отдельное учебное хранилище.
4. Получи gateway_corporate_skill_list. Для нужного навыка прочитай SKILL.md через gateway_corporate_skill_read. Возьми действительные ID, pack и version из ответа; не подставляй версию из примера. Старые примеры навыка могут перечислять только Codex/Claude/ChatGPT: для новых поддержанных клиентов используй реальные значения из пункта 2. Остальные ограничения навыка сохраняются.
5. Только при фактическом применении навыка вызови gateway_telemetry_skill_started с реальными agent/client, ID/pack/version, project="platforma-training", фактическим session_id (или пустой строкой) и metadata_json="{}". Сохрани correlation_id. Чтение навыка само по себе не является запуском.
6. После готовности и проверки результата вызови gateway_telemetry_skill_completed с тем же correlation_id. При ошибке после успешного started вызови gateway_telemetry_skill_failed с коротким техническим error_class. Если started отклонён, сообщи причину: не создавай завершение без начала и не меняй название приложения ради обхода.
7. mcp_routes_json содержит только фактически вызванные бизнес-маршруты platforma.context.get, platforma.services.list/get, platforma.requests.list/get/create/update. Не включай имена gateway_* инструментов. Не передавай текст запроса, содержимое заявок, имена, пароли или токены в metadata.
8. Создание и изменение вымышленных заявок выполняй только по явному поручению. Используй idempotency_key; для update перечитай точную revision; после записи проверь карточку чтением. Не повторяй запись после ошибки соединения с новым ключом: сначала проверь результат и используй прежний ключ для точного повтора. Для повторного осмысленного изменения нужен новый ключ и актуальная версия.
9. 401 требует обновления личной авторизации. Refresh не расширяет старый набор scopes. Если после выдачи учебных прав нет platforma:write или telemetry:write, нужен новый личный вход. Не переходи на SSH, общий аккаунт или другую identity.
10. Доступны учебные сервисы/заявки, общая карта и навыки; статистика навыков — только собственная. Память владельца, его статистика, реальные CRM/почта/инфраструктура и произвольное администрирование этим подключением не открываются.

Поля agent/client — самодекларируемые метки учёта, а не проверенная сервером личность программы. Действующий пользователь определяется OAuth.
