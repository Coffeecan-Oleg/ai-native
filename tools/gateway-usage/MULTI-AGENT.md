# Поддержка агентов 1.2.0

Codex: codex_jsonl, существующий адаптер.
Claude Code: claude_code_jsonl, только явно выбранный журнал sessionId/cwd. Формат локальных журналов не является стабильным API: сначала проверьте реальную схему установленной версии и завершённый message.stop_reason. Если usage/final недоступны — этот адаптер не активировать, выбрать официальный API/SDK/OTel.
Claude API / Agent SDK: anthropic_jsonl, окончательные числовые usage каждого вызова. Источник создаёт интеграция клиента после финального ответа. Не складывать assistant usage и итоговый ResultMessage за те же вызовы. Для SDK можно экспортировать итоговый usage один раз на SDK-запуск с уникальным ID запуска, не суммируя отдельно его сообщения. Покрытие отразить в отчёте.
Другие агенты: usage_jsonl, нормализованный числовой экспорт из их проверенного API/hook. Универсального доступа ко всем внутренним счётчикам клиентов нет.
Claude web/Desktop обычный чат: счётчики не гарантированы. Это не Claude Code. При отсутствии доступного usage статус model_tokens=unavailable, а не ноль. MCP context_volume показывать отдельно, не переводить в токены модели.

Anthropic input_tokens не содержит cache_read_input_tokens и cache_creation_input_tokens. В общий input записывается сумма этих трёх категорий. cached_tokens — часть общего input, повторно не прибавляется. Поле cache_creation_tokens оставляется в числовом экспорте, но отдельный вывод его серверным dashboard не гарантирован. Денежную стоимость по одному общему input считать нельзя. Reasoning отдельно не добавляется к output. Подписочные лимиты и реальные счета не выводятся из этих чисел.

Безопасность: выбирать только согласованные файлы/сессии, не сканировать все чаты и не передавать тексты. source_id стабилен при повторном запуске. Изменение source_id/state требует проверки точки начала, иначе возможен двойной импорт.

Проверка: python -m unittest test_usage_meter.py test_portable_export.py test_claude_export.py
Автоматические тесты синтетические. Реальный журнал/SDK и расписание проверяет агент установщика у студента. Отсутствующие counters нельзя заменять выдуманными.
