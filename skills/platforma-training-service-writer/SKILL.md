# Учебное создание и изменение заявок

Источник: https://kromin.axion-test.akmetron.ru/mcp. Работай только с вымышленными
данными по явному поручению владельца. Перед изменением покажи точные поля,
ожидаемый эффект и способ проверки; применяй только согласованное. Вопросы по одному.

Проверь gateway_access_profile: своя личная identity, scope platforma:write и действующее одобрение владельца для участника практикума. Одобренный участник практикума действует только в учебной песочнице. Получи gateway_search_tools и platforma.context.get;
при выключенном sandbox_write_pilot запись не выполняй. Учебные даты, периоды
и просрочка считаются относительно snapshot_as_of, не сегодняшней даты.

Создание: прочитай реальный ID учебного шаблона через platforma.requests.get,
покажи заимствуемые сервис, подразделение, заказчика и ответственного. После
согласования вызови platforma.requests.create с template_request_id, title,
due_at, необязательными priority/created_at. Не придумывай ID. Создание копирует
связи шаблона; дата создания по умолчанию равна дате учебного снимка.

Изменение: перечитай карточку, возьми её revision, покажи изменения и используй
platforma.requests.update с request_id, expected_revision и changes. Допустимы
title, priority, due_at, assignee_id того же подразделения, accepted_at,
reason, next_action, effort_hours. accepted_at=null возвращает заявку в работу;
дата завершения определяет early/exact/late автоматически. Созданная и принятая
даты не позже снимка; срок не раньше создания. Не передавай дополнительные поля.

Для каждой новой операции создай UUID idempotency_key. Повтор того же запроса
использует тот же ключ. При изменении payload нужен новый ключ и, если изменился
эффект, новое согласование. При REVISION_CONFLICT перечитай карточку и покажи
различие, не повторяй старую запись. Удаления нет. Нет оснований менять статусы
или ответственных просто для заполнения примера.

После успешного вызова обязательно прочитай карточку через requests.get и
сверь изменённые поля/revision/source. Зафиксируй gateway_request_id и результат.
Базовый снимок неизменяемый; новые данные и правки сохраняются в отдельном
хранилище песочницы. Для отката конкретной правки нужен новый согласованный
запрос с актуальной revision; не удаляй файл хранилища и том.

При отказе останови запись и сообщи причину, не переходи на SSH/другую identity.
Не отправляй реальные персональные данные, секреты или корпоративные записи.
Срок доступа прежний: до 31 октября 2026 включительно.

## Учёт содержательного применения навыка

Это учёт фактической работы по поручению пользователя. Чтение инструкции само
по себе не является запуском. При применении этого навыка к задаче, если инструменты
доступны и разрешены, перед началом вызови gateway_telemetry_skill_started:
agent и client выбери по фактическому приложению: codex/codex-desktop,
claude/claude-desktop, claude/claude-code, chatgpt/chatgpt. Не выдавай Claude или ChatGPT за Codex. Остальные поля: skill_id="platforma-training-service-writer",
skill_pack="platforma-training", skill_version="0.1.1", project="platforma-training".
session_id — фактический ID этого чата, если известен; иначе пустая строка.
metadata_json всегда "{}". Сохрани возвращённый correlation_id.

Когда результат готов и проверен, вызови gateway_telemetry_skill_completed с теми
же полями и correlation_id. Для ошибки после успешного started вызови
gateway_telemetry_skill_failed с тем же correlation_id и кратким техническим
error_class. Передавай только длительность и фактически использованные маршруты
platforma.context.get, platforma.services.list, platforma.services.get,
platforma.requests.list, platforma.requests.get, platforma.requests.create, platforma.requests.update
через mcp_routes_json. Не передавай текст запроса, карточки, данные документов,
аргументы маршрутов, имена людей, секреты или свободные комментарии. Недостающие
разрешения указываются только техническими именами scope.

Событие completed означает готовность результата со стороны ассистента, а не
приёмку владельцем. Не создавай задним числом события о прошлых сообщениях.
Если инструменты учёта недоступны или сервер отказал, сообщи отсутствие учёта и
продолжай разрешённую основную задачу; не расширяй доступ и не повторяй запись
другим способом. Для чтения своей статистики есть gateway_telemetry_skill_stats
с project="platforma-training". Чужую identity не выбирай.
